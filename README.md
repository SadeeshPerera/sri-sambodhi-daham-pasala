## 🌸 About the Project / ව්‍යාපෘතිය පිළිබඳ හැඳින්වීම
This is a state-of-the-art, fully responsive, and highly animated official website built for **Sri Sambodhi Daham Pasala (ශ්‍රී සම්බෝධි දහම් පාසල)** celebrating its momentous **50th Golden Jubilee Anniversary (1977 - 2027)** under the motto **“දැහැමින් ඉදිරියට” (Forward with Righteousness)**.

The website was designed with 20+ years of senior web architectural experience, following the gold standard of modern Buddhist educational platforms in Sri Lanka (incorporating the cultural values of the Department of Buddhist Affairs and top institutions like Siri Vajirarama Daham Pasala).

## ⚡ Engineering & Animation Highlights
- **Sacred Temple Bell / Singing Bowl Chime**: Built using the browser's native **Web Audio API** (432Hz fundamental + harmonic overtones), producing crystalline Buddhist temple meditation chimes with zero external audio dependencies.
- **Theme Engine**: Light Mode (Serene Ivory & Buddhist Maroon) and Dark Mode (Tranquil Temple Night) with persistent `localStorage` synchronization.
- **Buddhist Flag Strip**: Authentic six-color strip styling matching the exact hues and proportional layout of the International Buddhist Flag.
- **Scroll Progress & Reveal**: Real-time reading progress bar and smooth `IntersectionObserver` scroll-reveal animations.
- **Live Golden Jubilee Countdown**: Real-time countdown to January 1, 2027.
- **Dynamic Dhammapada Verse Generator**: Randomized Buddhist stanzas with Pali text, Sinhala explanation, and English translation.
- **Interactive Multi-Step Admissions Wizard**: Step-by-step progress tracking, validation, and auto-generated printable admission slip.
